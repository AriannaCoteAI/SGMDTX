🔒 安全提示：您的 Token 僅加密儲存在本機瀏覽器的 localStorage 中，不會傳送至任何第三方伺服器。

📖 使用說明：如何申請 GitHub Fine-grained PAT 與倉庫結構

1. 建立 GitHub 倉庫：建立一個新的公開或私有 Repo（例如 sanmou-ai-tools），並初始化 main 分支。

2. 申請 Fine-grained Token：前往 GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。

3. 設定權限：選擇上述倉庫，並在 Repository permissions 中將 Contents 設為 Read and write，複製產生的 Token 貼上即可。

4. 自動管理的檔案結構：每次上傳或更新工具時，平台會自動寫入 tools/您的檔名.html 並自動維護 tools/manifest.json 清單，無需手動建立！
