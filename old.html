GitHub Pages 上傳與動態更新設定教學

如何將此網站部署至 GitHub Pages 並透過更改 CSV 來更新網站資料

1

上傳至 GitHub 儲存庫

將本檔命名為 index.html，並將你的 CSV 數據檔命名為 data.csv，一起上傳至 GitHub Repository 根目錄。

2

開啟 GitHub Pages

進入專案 Settings ➔ Pages，在 Source 選擇 Deploy from a branch，分支選 main / root 並儲存。

3

日後改檔自動更新

未來需要維護隊伍資料時，只需在 GitHub 網站上點擊 data.csv 進行修改或覆蓋，網頁重整即會自動載入最新數據！
