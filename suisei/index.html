📖 使用說明：如何讓流星街盟友免登入直接查看工具

1. 公開倉庫免 Token 讀取：只要您的倉庫設為 Public，任何外部瀏覽器都不需要 Token 或登入 GitHub，系統會自動透過 GitHub Raw 通道秒速載入所有已上傳的工具。

2. 三種讓外部瀏覽器自動連上公開倉庫的方式：

  • GitHub Pages 自動偵測（最推薦）：將此 HTML 放進該 Public 倉庫並開啟 GitHub Pages，盟友打開網址就會自動抓到同倉庫的工具！
  • 直接寫入預設設定：在程式碼中的 DEFAULT_PUBLIC_REPO 填入您的 owner 與 repo。
  • 使用分享連結：點擊下方「複製公開分享連結」，貼到流星街群組，大家點開免設定即可直接使用。

3. 管理員權限（飛羽舞霜專用）：只有您需要新增、編輯或刪除工具時，才需要在此輸入具 Contents: Read and write 權限的 Fine-grained PAT。
